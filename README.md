# WeBid

WeBid is an online eCommerce auction application that allows users to register and create both forward and dutch auctions.

## Tech Stack
- Frontend: ReactJS
- Backend: SpringBoot
- Database: TBD
- Messaging Services: TBD
- Hosting Platform: TBD

### Architecture Style
This application uses primarily the MVC (Model View Controller) design architecture to split up the codebase into core classes/objects being the Model, all of our UI components are Views, and we have Controller services that interact with our Model Components
